# Kouros Portfolio — Front-end

Portfolio vitrine de Kouros Salari, construit avec [Next.js](https://nextjs.org).

## Installation

\`\`\`bash
cd kouros-portfolio
npm install
\`\`\`

## Lancer en développement

\`\`\`bash
cd kouros-portfolio
npm run dev
\`\`\`

Ouvrir [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js

## Déploiement

Déployé sur [Vercel](https://vercel.com).
